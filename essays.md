## 1. Briefly describe what this code sample does.

The code sample is for Accessibility Hub, A website I am working on that aims to create a community focused on accessibility. The two main features of the website are:

1. Reviews: Allows users to review and comment on the accessibility of a software / hardware.
2. Discussions: Allows users to create topics, in form of questions or information that are also focused on accessibility.

The website has Authentication and Authorisation as well.

Technologies used in the website include:

* Django: Python web frame work.
* MySQL: A SQL database.
* Htmx: A library that brings modern browser features to html via html attributes.
* Nginx: A web server.
* Fabric: A library for executing shell commands remotely over ssh

## 2. Briefly describe what you learned when you created this code sample

One of the things I learnt while building accessibility hub was Django. Accessibility hub was the first website I built with django. I learnt about django forms, django middle ware, django templates, django views, django auauth... django itself. On the other hand, htmx opened my mind to a different way of adding reactivity to websites. Htmx builds on HATEOAS (Hyper-Media As The Engine Of Application State). The different thing about htmx is that the reactivity of a page is in it's html. This follows the localization of concern principle.
